Token launch radar — rank pre-token protocols by implied launch value. It reads a sealed snapshot of every protocol DefiLlama tracks, finds the ones with no token that are not a wrapped or staked product of one that trades, and ranks them by what their launch would be worth. A web dashboard shows the board, a detail view for each protocol, and the steps to farm it.

## Run it

```sh
node main.ts
```
